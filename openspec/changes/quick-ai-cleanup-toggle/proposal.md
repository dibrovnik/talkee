# Proposal

## Why

Сейчас ИИ-очистка диктовки (пунктуация, удаление слов-паразитов, стиль) работала только через облако Talkis. В режимах «API» и «Локально» она отключена в коде (`ai.rs:1044-1047`, «style cleanup is disabled by policy»; `transcriptionPipeline.ts` всегда отправляет `llm_model: "none"`). После `remove-talkis-cloud` очистки нет совсем.

Пользователю нужно, чтобы очистка работала на собственных ключах и на локальной LLM и включалась мгновенно — без захода в настройки: горячей клавишей, из трея или правым кликом по виджету.

## What Changes

**Очистка в API и локальном режимах**
- После распознавания текст обрабатывается выбранным промптом очистки через текстовый backend (`resolveSummaryBackend`: свой endpoint или локальная LLM).
- Работает таймаут: 8 с для API, 12 с для локальной LLM.
- При ошибке, таймауте или отклонённом `transcriptionGuard` результате вставляется исходный текст и показывается короткое уведомление.

**Настройки**
- `cleanupEnabled` — по умолчанию выключено.
- `cleanupToggleHotkey` — по умолчанию `Control+Option+C`, можно очистить.
- Существующий `selectedCleanupPromptId` определяет стиль.

**Быстрые переключатели**
- Глобальная горячая клавиша включает и выключает очистку.
- В меню трея: пункт-галочка «ИИ-очистка текста» и подменю «Стиль очистки» с радио-пунктами пресетов.
- Правый клик по виджету открывает нативное контекстное меню с теми же пунктами.
- Переключатель в верхней части вкладки «Стиль».

**Обратная связь**
- Уведомление виджета «ИИ-очистка включена · Классический» или «ИИ-очистка выключена» на 1,5 с.
- Постоянный индикатор на пилюле: маленькая «искра», пока очистка включена.
- Когда очистка включена, а модель для неё не настроена, очистка не включается. Вместо этого показывается подсказка с действием «Выбрать модель».

**Локальная LLM**
- При включении очистки локальная LLM прогревается заранее.
- Для моделей с режимом размышлений (Qwen3) он отключается, блоки `<think>…</think>` вырезаются из ответа.

**История**
- В истории сохраняются и исходный, и очищенный текст. Пользователь может посмотреть исходный.

Зависит от: `native-macos-ui` — нужны новое меню трея и примитивы UI.

## Capabilities

### New Capabilities
- `text-cleanup`: ИИ-очистка распознанного текста в режимах «API» и «Локально», её быстрое включение и выключение, поведение при ошибках и сохранение в истории.

## Impact

- **Frontend:**
  - `src/lib/store.ts` — новые поля, валидация горячей клавиши через `validateHotkey()`;
  - `src/windows/widget/services/transcriptionPipeline.ts` — шаг очистки;
  - `src/windows/widget/services/transcriptionGuard.ts`;
  - `src/lib/summarize.ts` — переиспользование `generatePromptText`;
  - `src/windows/widget/hooks/useWidgetHotkey.ts` — третья горячая клавиша;
  - `src/windows/widget/Widget.tsx` — индикатор и контекстное меню;
  - вкладка «Стиль»;
  - i18n.
- **Rust:**
  - `src-tauri/src/ai.rs` — удалить заглушку «disabled by policy», если очистка останется на стороне TS;
  - `src-tauri/src/tray.rs` — `CheckMenuItem` и подменю;
  - `src-tauri/src/llm_runtime.rs` / `sidecars/talkee-llm` — отключение thinking и прогрев;
  - события синхронизации состояния между окнами.
- **История:** формат записи с полями `raw` и `cleaned` — проверить, есть ли они уже.
