# network-privacy Specification

## Purpose
Гарантирует, что talkee выходит в сеть только по явному действию пользователя или к адресам, которые пользователь сам настроил, и что это правило проверяется автоматически.

## Requirements

### Requirement: No background network traffic
Приложение MUST NOT выполнять сетевые запросы, которые не инициированы явным действием пользователя и не адресованы настроенному пользователем endpoint'у. Сюда относятся проверки обновлений, загрузка шрифтов, аналитика, crash-репорты, «пинги» и запросы профиля.

#### Scenario: Запуск без действий пользователя
- **WHEN** пользователь запускает приложение и ничего не делает 10 минут
- **THEN** приложение не открывает ни одного исходящего соединения, кроме соединений с `127.0.0.1`/`localhost` для управляемых локальных sidecar-процессов

#### Scenario: Открытие настроек
- **WHEN** пользователь открывает окно настроек
- **THEN** не выполняется ни проверка обновлений, ни загрузка удалённых шрифтов, стилей или изображений

### Requirement: Allowed network destinations
Приложение SHALL обращаться в сеть только в трёх случаях: (1) к endpoint'ам STT/LLM/Realtime, которые пользователь настроил или выбрал из списка провайдеров; (2) для загрузки модели или runtime-компонента после явного нажатия пользователем кнопки загрузки; (3) по ссылке, которую пользователь явно открыл во внешнем браузере.

#### Scenario: Диктовка в локальном режиме
- **WHEN** активен режим «Локально» и пользователь диктует текст
- **THEN** все запросы идут только на `127.0.0.1`/`localhost`

#### Scenario: Загрузка модели
- **WHEN** пользователь нажимает «Скачать» у локальной модели
- **THEN** приложение загружает файл только с URL, указанного в каталоге моделей для этой модели

### Requirement: No auto-update mechanism
Приложение MUST NOT содержать механизм автоматической проверки или установки обновлений.

#### Scenario: Меню трея
- **WHEN** пользователь открывает меню трея
- **THEN** в нём нет пункта «Проверить обновления»

### Requirement: Automated host allowlist check
Репозиторий SHALL содержать проверку, которая сканирует исходники приложения (`src/`, `src-tauri/src/`, `src-tauri/sidecars/`, `index.html`, `src/index.css`) на абсолютные URL и завершается с ненулевым кодом, если найден хост вне allowlist. Allowlist хранится в одном файле в репозитории, и каждая запись в нём снабжена комментарием с причиной. Allowlist MUST NOT содержать хостов `talkee.ru` и его поддоменов, а также секции отложенного удаления.

#### Scenario: Добавлен запрещённый хост
- **WHEN** разработчик добавляет в код `https://fonts.googleapis.com/...`
- **THEN** `bun run check:network` завершается с ошибкой и печатает файл, строку и хост

#### Scenario: Чистое дерево
- **WHEN** в коде есть только хосты из allowlist
- **THEN** `bun run check:network` завершается с кодом 0

#### Scenario: Возврат облачного хоста
- **WHEN** в коде появляется `https://proxy.talkee.ru/api/transcribe`
- **THEN** `bun run check:network` завершается с ошибкой
