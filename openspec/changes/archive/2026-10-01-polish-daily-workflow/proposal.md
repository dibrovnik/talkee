# Proposal

## Why

Повседневный сценарий — потоковое распознавание русского через Nemotron и очистка через DeepSeek — теряется среди множества моделей и мелких элементов управления. Созвоны должны запускаться из трея и сохранять звук, а длинные видео — обрабатываться без потери состояния при навигации с понятным прогрессом; статистика должна объяснять реальную пользу диктовки.

## What Changes

- Добавить «Начать запись созвона» в нативный трей, использовать существующий сценарий захвата и общие проверки занятости/разрешений.
- Перестроить основное окно по мотивам веб-версии ChatGPT: спокойная боковая панель, просторная рабочая область, читаемый транскрипт, заметные действия и единая шкала размеров. Сохранить системные светофоры, темы, горячие клавиши и геометрию виджета.
- Использовать готовые доступные компоненты Radix Primitives через существующий слой `src/ui`; это React-библиотека, а не AppKit и не готовая macOS-тема. Внешний вид адаптировать к macOS и выбранному образцу.
- Разделить настройку распознавания и ИИ-обработки: локальный Nemotron + DeepSeek API — допустимая и основная комбинация. Показать активные модели, состояния загрузки и проверки, простые переключатели и явные действия выбора.
- Сократить локальное распознавание до Nemotron 3.5 ASR Streaming 0.6B, GigaAM v3 и Whisper large-v3-turbo; убрать англоязычные и избыточные предложения. Для API оставить короткий список русскоязычных вариантов OpenAI/Groq и ручной endpoint для совместимости.
- Оставить для локальной очистки Qwen3 1.7B Q4 и Qwen2.5 3B Instruct Q4; DeepSeek API — основная рекомендация. Не загружать локальную LLM при выбранном API, не обещать отсутствие нагрузки без измерений. Существующие установки и ключи не удалять автоматически.
- Вынести владение файловыми задачами из вкладки в общий сервис владельца-виджета; показывать этапы, обработанную длительность, приблизительный остаток времени и доступный результат. Закрытие окна означает скрытие, а не остановку задачи. **Восстановление после полного выхода из приложения не входит в объём.**
- Закрепить независимое сохранение дорожек созвона при выключенном сохранении обычной диктовки; сохранить воспроизведение, повторную обработку и действующие правила удаления истории.
- Добавить раздел статистики: графики слов и времени за период, разрезы по источникам/моделям, скорость диктовки, оценка экономии только для диктовки; скорость печати задаётся вручную или коротким локальным тестом.

## Capabilities

### New Capabilities

- `call-recording`: запуск созвона из трея и независимое сохранение его аудио.
- `file-transcription-jobs`: единая файловая задача, непрерывная работа при скрытии окна/смене вкладок, честный прогресс и ETA.
- `usage-analytics`: локальная статистика и оценка сэкономленного времени.

### Modified Capabilities

- `native-appearance`: более просторная компоновка и компоненты вместо обязательной имитации компактных AppKit-форм.
- `processing-modes`: независимый выбор STT/LLM и короткий каталог рекомендованных моделей.

## Impact

Изменятся `src/ui`, `src/index.css`, окно настроек и его страницы, каталоги STT/LLM, файловый сценарий и события, нативный трей, статистика и документация. Добавятся только используемые пакеты Radix; графики — SVG без отдельной графической библиотеки. Существующие правила `native-appearance` и `rules/style.rule.md` о 13 pt/22 px и исключительно системных формах заменяются явно, остальные ограничения приватности и доступности сохраняются. Общий таймаут очистки 8/12 секунд и безопасный возврат исходного текста не меняются.

## Depends on

Новых зависимостей от неархивированных изменений нет. Незакоммиченный `fix-idle-cpu-loop` и его тест не изменять и не включать в коммиты этого изменения.
