# Spec Delta

## MODIFIED Requirements

### Requirement: Cleanup in API and local modes
Если ИИ-очистка включена для текущей записи, приложение SHALL после распознавания диктовки обработать текст выбранным промптом очистки через настроенную текстовую модель: пользовательский endpoint в режиме «API» или локальную LLM в режиме «Локально». Основная клавиша диктовки и клик по виджету MUST учитывать глобальный переключатель; отдельная клавиша ввода с очисткой MUST включать очистку только для текущей записи, не меняя переключатель. При успехе SHALL использоваться очищенный текст, затем SHALL применяться независимо включённый персональный словарь перед переводом и вставкой.

#### Scenario: Локальная очистка
- **WHEN** активен локальный текстовый backend, очистка включена со стилем «Классический» и пользователь диктует «ну короче давай встретимся завтра в три»
- **THEN** в активное приложение вставляется очищенный текст без явных слов-паразитов и с пунктуацией, например «Давай встретимся завтра в три.»

#### Scenario: Очистка выключена
- **WHEN** очистка выключена
- **THEN** запрос к текстовой модели не выполняется; вставляется исходный STT-текст с утверждёнными точными заменами, если персональный словарь независимо включён

#### Scenario: Основная клавиша при включённой очистке
- **WHEN** глобальная очистка включена и запись начинается основной клавишей в режиме удержания или переключения
- **THEN** выполняется очистка через выбранный backend, а не молчаливый пропуск с причиной «выключена»

#### Scenario: Отдельная клавиша при выключенном переключателе
- **WHEN** переключатель выключен и пользователь начинает запись клавишей ввода с очисткой
- **THEN** эта запись очищается, сохранённый переключатель остаётся выключенным, следующая обычная запись не очищается

### Requirement: Safe fallback to raw text
Если очистка завершилась ошибкой, превысила таймаут (8 секунд для API, 12 секунд для локальной LLM) или её результат отклонён проверкой качества, приложение SHALL сохранить исходный STT и использовать его как fallback с последующими утверждёнными заменами независимо включённого словаря. Уведомление MUST отличать возврат исходника от его нормализации словарём. Распознанный текст MUST NOT теряться. По таймауту SHALL отменяться HTTP-операция; поздний результат MUST NOT применяться, общий runtime MUST NOT останавливаться.

#### Scenario: Таймаут локальной модели
- **WHEN** локальная модель не ответила за 12 секунд и словарь выключен
- **THEN** вставляется исходный текст, показывается уведомление «Очистка не удалась — вставлен исходный текст», в логе есть причина и длительность

#### Scenario: Служебные блоки размышлений
- **WHEN** модель вернула ответ с блоком `<think>…</think>`
- **THEN** блок вырезается, и дальнейшая проверка и нормализация получают только итоговый текст

#### Scenario: Fallback со словарём
- **WHEN** очистка не удалась, исходный STT содержит «пим», а утверждённый словарь заменяет его на PIM
- **THEN** вставляется PIM, сохраняется настоящий исходник, уведомление сообщает «Очистка не удалась — применён словарь»

### Requirement: History keeps raw and cleaned text
Запись истории диктовки SHALL хранить исходный STT и окончательный обработанный текст при очистке или персонализации. По умолчанию MUST отображаться итог, пользователь MUST иметь возможность посмотреть и скопировать исходник. Если словарь изменил результат LLM, SHALL сохраняться необязательный текст до нормализации с происхождением изменения; старые записи без новых полей MUST продолжать открываться.

#### Scenario: Просмотр исходного текста
- **WHEN** пользователь открывает запись, созданную с очисткой
- **THEN** он видит итоговый текст и может переключиться на «Исходный текст»

#### Scenario: Только словарь
- **WHEN** очистка была выключена, а словарь применил замену
- **THEN** оригинал STT и итог не смешиваются; подпись объясняет, что текст изменён словарём

### Requirement: Unavailable cleanup is visible
Если очистка включена для записи, но текстовый backend недоступен по конфигурации, приложение SHALL сохранить исходный STT, выполнить утверждённые замены независимо включённого словаря и вставить доступный результат. Оно MUST показать уведомление выбора модели и записать конкретную безопасную причину отсутствия вызова.

#### Scenario: Сохранённая модель удалена
- **WHEN** очистка включена, но модель имеет значение `none` или не задана
- **THEN** HTTP-запрос не выполняется, пользователь видит причину/выбор модели, лог отличает недоступный backend от выключенного переключателя, словарь не требует LLM

## ADDED Requirements

### Requirement: Approved glossary augments the existing cleanup request
Включённая очистка SHALL получать ограниченный список активных утверждённых написаний как данные дополнительно к выбранному пресету. Приложение MUST NOT переписывать пользовательский промпт, заменять выбранный стиль, включать очистку скрыто или выполнять второй запрос для проверки словаря.

#### Scenario: Пользовательский пресет
- **WHEN** выбран собственный промпт и активен персональный словарь
- **THEN** выполняется один запрос с действующим собственным промптом и компактными активными написаниями; сохранённый текст пресета не меняется
