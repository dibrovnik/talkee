# Spec Delta

## Purpose

Определяет режимы обработки речи и текста в talkee (только «API» и «Локально»), правило выбора активного режима и миграцию со старого облачного режима Talkis.

## ADDED Requirements

### Requirement: Exactly two processing modes
Приложение SHALL поддерживать ровно два режима обработки: «API» (запросы к endpoint'ам, настроенным пользователем, с его ключами) и «Локально» (запросы к управляемым sidecar-процессам или другим серверам на `localhost`/`127.0.0.1`). Приложение MUST NOT содержать режима, аккаунта, подписки или баланса, связанного с каким-либо облачным сервисом разработчика.

#### Scenario: Вкладка моделей
- **WHEN** пользователь открывает вкладку «Диктовка и модели»
- **THEN** он видит выбор только между «API» и «Локально», и нигде в настройках нет входа в аккаунт, подписки, баланса или кнопки «Пополнить»

#### Scenario: Определение активного режима
- **WHEN** STT endpoint указывает на `localhost` или `127.0.0.1`
- **THEN** активный режим — «Локально»; иначе — «API»

### Requirement: Default mode on clean install
При первом запуске без сохранённых настроек приложение SHALL выбрать режим «Локально» и в онбординге предложить скачать локальную STT-модель, не выполняя никаких сетевых запросов до явного действия пользователя.

#### Scenario: Первый запуск
- **WHEN** пользователь впервые запускает приложение
- **THEN** активен режим «Локально», модель не скачана, и онбординг показывает кнопку загрузки модели

#### Scenario: Диктовка без модели
- **WHEN** пользователь нажимает горячую клавишу диктовки, а ни API, ни локальная модель не настроены
- **THEN** запись не начинается, и виджет показывает понятное сообщение с действием «Открыть настройки моделей»

### Requirement: Migration from legacy cloud mode
При загрузке настроек, сохранённых старой версией, приложение SHALL удалить поле `deviceToken` из постоянного хранилища и перевести пользователя со старого облачного режима (`useOwnKey=false`) в «Локально», если локальная STT-модель установлена, иначе в «API». Все прочие настройки (горячие клавиши, язык, промпты, история) MUST сохраниться.

#### Scenario: Пользователь облака с установленной локальной моделью
- **WHEN** сохранены `useOwnKey=false`, `deviceToken="abc"` и установлена локальная модель Whisper
- **THEN** после запуска активен режим «Локально», `deviceToken` отсутствует в файле настроек, горячая клавиша прежняя

#### Scenario: Пользователь облака без локальной модели
- **WHEN** сохранены `useOwnKey=false` и нет ни одной локальной модели
- **THEN** активен режим «API» с пустым ключом, и при первой попытке диктовки показывается сообщение о необходимости настроить модель

### Requirement: Legacy history compatibility
Записи истории, созданные в облачном режиме (например, с `provider: "cloud"` или `"talkis-cloud"`), SHALL открываться, отображаться и искаться без ошибок.

#### Scenario: Открытие старой записи
- **WHEN** пользователь открывает запись истории с `translation.provider = "cloud"`
- **THEN** запись отображается полностью, а источник показан нейтрально (например, «Облако (устарело)») без ссылок на внешние сервисы

### Requirement: Managed local runtime is bundled
Управляемые локальные runtime (STT, диаризация, LLM, ffmpeg) SHALL запускаться только из бинарников, встроенных в сборку приложения. Приложение MUST NOT скачивать исполняемые файлы runtime из сети.

#### Scenario: Отсутствует встроенный STT sidecar
- **WHEN** встроенный STT sidecar не найден в бандле
- **THEN** локальный режим показывает ошибку «Локальный STT runtime не найден в сборке приложения» и не делает сетевых запросов

### Requirement: No external vendor links
Меню трея, окно «О программе» и окно настроек MUST NOT содержать ссылок на сайт, репозиторий, страницу приватности или почту поддержки Talkis.

#### Scenario: Меню трея
- **WHEN** пользователь открывает меню трея
- **THEN** в нём нет пунктов «Поддержка», «GitHub», «Приватность», а окно «О программе» показывает только название, версию и лицензию
