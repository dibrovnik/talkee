# Spec Delta

## MODIFIED Requirements

### Requirement: Exactly two processing modes
Приложение SHALL поддерживать ровно два режима обработки: «API» (пользовательские endpoint и ключи) и «Локально» (управляемые sidecar или пользовательские loopback-серверы). Режим распознавания и режим текстовой обработки MUST выбираться независимо; локальный STT с DeepSeek API MUST работать без переключения STT в API. Режим STT определяется его endpoint, текстовый режим — текстовым endpoint. Приложение MUST NOT содержать аккаунта, подписки или баланса сервиса разработчика.

#### Scenario: Вкладка моделей
- **WHEN** пользователь открывает модели
- **THEN** распознавание и ИИ-обработка представлены отдельными секциями с выбором «API» или «Локально», без входа в аккаунт Talkee

#### Scenario: Определение активного режима
- **WHEN** STT endpoint указывает на `localhost` или `127.0.0.1`
- **THEN** распознавание работает локально независимо от текстового endpoint

#### Scenario: Основной смешанный сценарий
- **WHEN** выбраны локальный Nemotron и настроенный DeepSeek API
- **THEN** речь распознаётся локально с доступным streaming, а включённая очистка выполняется через DeepSeek без запуска локальной LLM

## ADDED Requirements

### Requirement: Curated Russian model selection
Каталог предложений SHALL содержать только отобранные модели с поддержкой русского: локальные STT Nemotron 3.5 ASR Streaming 0.6B, GigaAM v3 и Whisper large-v3-turbo; API STT — OpenAI GPT-4o Transcribe и Groq Whisper large-v3-turbo. Англоязычные и дублирующие предложения MUST быть убраны. Текстовые рекомендации SHALL включать основной DeepSeek API и локальные Qwen3 1.7B Q4 / Qwen2.5 3B Instruct Q4. Ручная настройка endpoint MUST оставаться доступной отдельно от рекомендаций.

#### Scenario: Выбор русскоязычного STT
- **WHEN** пользователь открывает локальные модели
- **THEN** видит три предложения с назначением, размером и честной маркировкой streaming; Nemotron отмечен как основной сценарий

#### Scenario: Старые установки
- **WHEN** выбранная ранее модель больше не входит в рекомендации
- **THEN** её файлы и настройки не удаляются автоматически, она видна как ранее установленная/настроенная и может использоваться или удаляться явно

### Requirement: Clear model activation and resource use
Интерфейс SHALL различать активную модель, просмотр категории, загрузку, запуск и проверку подключения; выбор просмотра MUST NOT менять рабочую конфигурацию. Основной DeepSeek MUST требовать ключ пользователя и явную настройку без скрытой отправки текста. Локальные текстовые модели MUST запускаться только при их выборе/использовании, с отключённым режимом размышления для очистки и ограниченным контекстом. Обещания качества и малой нагрузки MUST подтверждаться проверками.

#### Scenario: Интуитивный выбор
- **WHEN** пользователь переключает отображаемую категорию моделей
- **THEN** активная модель остаётся прежней до явного выбора, её название и состояние видны отдельно

#### Scenario: Лёгкая локальная очистка
- **WHEN** пользователь явно выбирает локальную текстовую модель
- **THEN** показаны размер и требуемая память; в процессе очистки нет длинных размышлений, а при таймауте сохраняется действующий безопасный возврат исходного текста
