# Proposal

## Why

Очистка включена в сохранённых настройках, но обычный hotkey принудительно передаёт `cleanup=false`: записи 5 октября 2026 года до 11:24 пропускают DeepSeek с `cleanup_reason=disabled`. Успешный запрос в 11:26 занял 1795 мс; требуется исправить выбор режима, убрать избыточные задержки и сделать причины пропусков/ошибок доступными для локальной диагностики.

## What Changes

- **BREAKING**: основная клавиша диктовки следует глобальному переключателю; отдельная клавиша «Ввод с очисткой ИИ» всегда включает очистку только для текущей записи. Пользователь явно подтвердил это поведение; комбинации клавиш и сохранённый переключатель не меняются.
- Уточнить индикацию текущей записи и русские подсказки, показать причину недоступного backend вместо молчаливого пропуска.
- Оптимизировать горячий путь: небольшой пул соединений только для текстовых запросов, компактный системный промпт, кеш встроенных промптов. Сохранить deadlines 8/12 секунд, безопасность fallback и сетевую политику; мгновенный ответ внешнего API не обещать.
- Адаптировать существующий стиль «Разработка» к реальным типам пользовательских диктовок: задачи агенту, Git, frontend/backend, API, PIM/MCP. Сохранять требования, отрицания, числа, порядок действий и точные идентификаторы, не выполнять диктуемые инструкции и не изобретать код.
- Добавить сквозные идентификаторы операций, причины решения о вызове, HTTP-статусы, времена, доступные token usage и ошибки без API-ключей, тел запросов/ответов и полных расшифровок.
- Ротировать `~/.talkee/talkee.log` по 5 МиБ с тремя архивами; очистка логов удаляет весь набор под той же блокировкой. Убрать уже существующее логирование полных расшифровок.

## Capabilities

### New Capabilities

- `diagnostic-logging`: локальная диагностика обработки, безопасные поля, ограниченный размер и ротация логов.

### Modified Capabilities

- `text-cleanup`: согласованность основной клавиши с переключателем, безопасная developer-очистка и интерактивная обработка без лишних запросов.

## Impact

- Frontend: `src/windows/widget/hooks/useWidgetHotkey.ts`, `useWidgetController.ts`, `useWidgetRecording.ts`, `src/windows/widget/services/widgetMachine.ts`, `transcriptionPipeline.ts`, `src/lib/textCleanup.ts`, `summarize.ts`, соответствующие тесты и словари подсказок.
- Rust: `src-tauri/src/ai.rs`, `src-tauri/src/prompt_config.rs`, `src-tauri/src/logger.rs`; существующие зависимости reqwest/url/tempfile, без новых пакетов.
- Промпты: `src/config/transcription-prompts/base/common.json`, `styles/tech.json`, `overrides/ru.tech.json`, `manifest.json`. Другие стили сохраняют свои отличия; пользовательские промпты не перезаписываются.
- Команды/документация: `package.json`, `docs/audio-pipeline-principles.md`, `docs/privacy.md`; существующие команды `bun run logs`, `bun run logs:clear` сохраняются.
- Тесты и runtime-проверка в dev-сборке; установленное приложение и ключи не изменяются на этапе планирования. Частные расшифровки не копируются в репозиторий.
